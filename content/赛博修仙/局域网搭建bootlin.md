# 安装基础环境

## docker安装elixir

```yaml
version: "3"
services: 
  web:
    image: jasonjang/bootlin-elixir:latest
    container_name: bootlin-elixir
    ports:
      - 8080:80
    volumes:
      - /path/to/docker/bootlin/elixir-data:/srv/elixir-data
      - /path/to/docker/bootlin/tmp:/srv/tmp
    environment:
      - PYTHONUNBUFFERED=1
    restart: always
```

## 通用步骤

1. 进入`bootlin-elixir`容器：`docker exec -it elixir-bootlin /bin/bash`
2. 配置环境：`. /usr/local/elixir/venv/bin/activate`
3. 增加库：`/usr/local/elixir/utils/index-repository <name> /srv/tmp/<name>`

## 部署linux源码

4. 获取linux源码
   1. 由官方下载页面下载：<https://www.kernel.org/>
   2. 找官方git库：<https://git.kernel.org/>
   3. 找github备份库：<https://github.com/torvalds/linux>
   4. 网络不好时找镜像库，清华镜像：<https://mirrors.tuna.tsinghua.edu.cn/help/linux.git/>
5. 在宿主进入`/path/to/docker/bootlin/tmp`目录
6. 创建bare仓库，此处我用的清华镜像
   - `git clone --bare https://mirrors.tuna.tsinghua.edu.cn/git/linux.git linux.git`
   - 获取所有tag：`git fetch --tags`
   - 我目前只需要v5.10的，那么执行`git tag | grep -v '^v5\.10$' | xargs git tag -d`
7. 执行通用步骤-① ②
8. 增加linux库：`/usr/local/elixir/utils/index-repository linux /srv/tmp/linux.git`
9. 打开网页验证：`http://宿主机ip:port`
   ![[赛博修仙/assets/局域网搭建bootlin-13.png]]

## 增加其他tag

10. 进入tmp目录 `cd /path/to/docker/bootlin/tmp`
11. 进入linux目录 `cd ./linux.git`
12. 比如我想获取stable下的新tag
    1. 增加新的远程仓库：`git remote add stable https://mirrors.tuna.tsinghua.edu.cn/git/linux-stable.git`
    2. 获取stable远程仓库的tag：`git fetch stable --tags`
    3. 删除不用的tag（比如我只想看v5.10下的tag）：  `git tag | grep -vE '^(v5\.10$|v5\.10\..``*|v5\.10-rc.*``)$' | xargs git tag -d`
13. 执行通用步骤-① ②
14. 进入repo `cd /srv/elixir-date/linux/repo`
15. 执行 `git fetch --tags`
16. 再次运行增加linux库：`/usr/local/elixir/utils/index-repository linux /srv/tmp/linux.git`
