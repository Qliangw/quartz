## 问题

1. 近日镜像服务器不提供服务了，咋办？
2. 当使用docker pull 总是超时，怎么办？
3. 当服务器只有局域网的时候，想要去获取docker镜像应该如何是好？

## 解决

### 方案一 使用俄罗斯镜像

`https://mirror.yandex.ru/`

优点：适合单独pull镜像使用，俄罗斯大厂提供服务

缺点：不支持配置到 `daemon.json`

使用方式：`docker pull cr.yandex/mirror/nginx`

> 前提是这镜像里得有，才能拉取

### 方案三 找个”中间人”

个人在用

中间人设备：可以访问dockerhub的机器

目标设备：访问不了dockerhub，且想要部署某个docker的设备

4. 找个可以正常访问dockerhub的机器— **中间人设备**
5. 使用 `docker pull` 命令拉取响应的镜像
6. 保存镜像 `docker save -o /path/to/xxx.tar xxx:laster`
7. 将保存的镜像存储到**目标设备**
8. 在**目标设备**执行`docker load -i/path/toxxx.tar `

> 示例
>
> ```python
>
> # 找一个可以上外网的机器
> docker pull nginx:1.26.1
>
> # 导出镜像
> docker save -o ./nginx-1.26.1.tar nginx:1.26.1
>
>  # 上传到目的服务
> ---------------------------------
>
>  # 在目的服务器上执行导入
>  docker load -i nginx-1.26.1.tar
>
